# 🚀 GitHub Pages 个人网站完整操作指南

**技术栈：Vue3 + Vite + Tailwind CSS v4 + pnpm**  
**参考模板：RyanFitzgerald/devportfolio**

> ⚠️ 本指南**全程使用 pnpm**，请勿混用 npm，否则会出现依赖冲突、`node_modules/.ignored` 警告、幽灵依赖报错等问题。

---

## 一、环境准备

确保电脑已安装：

| 工具 | 检查命令 | 建议版本 |
|------|----------|----------|
| Node.js | `node -v` | 18+ |
| pnpm | `pnpm -v` | 8+ |
| Git | `git --version` | 任意 |

如果没装 pnpm，用 npm 装一次即可（之后不再用 npm）：

```bash
npm install -g pnpm
```

检查是否有残留的旧项目环境：

```bash
Remove-Item -Recurse -Force node_modules -ErrorAction SilentlyContinue
Remove-Item package-lock.json -ErrorAction SilentlyContinue
```

---

## 二、创建 Vue3 + Vite 项目

```bash
pnpm create vite my-site --template vue
cd my-site
pnpm install
```

此时可以运行 `pnpm dev` 看到默认页面，确认项目正常后再继续。

## 三、安装并配置 Tailwind CSS v4

### 1. 安装依赖

```bash
pnpm add -D tailwindcss @tailwindcss/vite @types/node
```

> `@types/node` 用于让 TypeScript 识别 `path` 和 `__dirname`。

### 2. 修改 `vite.config.ts`

**这是关键一步**，一次性配置好别名、Tailwind 和 base 路径：

```typescript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import tailwindcss from '@tailwindcss/vite'
import path from 'path'

export default defineConfig({
  plugins: [vue(), tailwindcss()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
  // 部署时启用，值为 '/仓库名/'；若是 zjy-141.github.io 仓库则写 '/'
  // 本地开发可以先注释掉
  // base: '/my-site/',
})
```

> 💡 **为什么之前报 `@/data/config` 找不到？**  
> 就是因为缺少 `resolve.alias` 里的 `@` 配置。加上后，所有 `@/xxx` 的 import 都能被 Vite 正确解析。

### 3. 修改 `src/style.css`

**全部替换**为：

```css
@import "tailwindcss";

@theme {
  --font-mono: 'IBM Plex Mono', 'Fira Code', monospace;
}

html {
  scroll-behavior: smooth;
}

body {
  background-color: #0a0a0a;
  color: #c9d1d9;
  font-family: var(--font-mono);
  -webkit-font-smoothing: antialiased;
}
```

### 4. 修改 `index.html` 引入字体

在 `<head>` 中加入：

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500;600;700&display=swap" rel="stylesheet">
```

### 5. 修改 `package.json` 锁定包管理器（推荐）

在 `package.json` 顶层加一行：

```json
"packageManager": "pnpm@11.9.0"
```

这样别人用 npm 时会直接报错提示，避免混用。


> ⚠️ **所有组件统一使用 `@/data/config` 别名**。不要再写 `../data/config`，两种混着写容易出错，选一种风格统一即可。

## 八、本地预览

```bash
pnpm dev
```

打开 `http://localhost:5173`，应看到深色等宽字体主页。

**若报错，按以下对照排查：**

| 报错 | 原因 | 解决 |
|------|------|------|
| `@/data/config could not be resolved` | 没配 `@` 别名 | 检查 `vite.config.ts` 的 `resolve.alias` |
| `不存在属性 shijian` | `config.social` 缺字段 | 补上 `tuxun` 和 `shijian` |
| `Moving ... to node_modules/.ignored` | npm/pnpm 混用 | 删掉 `node_modules` 重新 `pnpm install` |
| `Cannot find module 'path'` | 缺 Node 类型 | `pnpm add -D @types/node` |
| 技术栈区域空白 | `skills` 结构错误 | 确保是 `{ category, items }` 对象数组 |
| 项目链接不显示 | `projects` 用错字段 | 确认使用 `links: [{ label, url }]` |

## 九、部署到 GitHub Pages

### 1. 启用 base 路径

编辑 `vite.config.ts`，取消注释 `base`：

```typescript
base: '/my-site/',  // 换成你的仓库名；若是 zjy-141.github.io 则写 '/'
```

### 2. 构建

```bash
pnpm build
```

会生成 `dist/` 目录。

### 3. 推送到 GitHub

在 GitHub 上新建仓库（例如 `my-site`），然后：

```bash
git init
git add .
git commit -m "init personal website"
git branch -M main
git remote add origin https://github.com/zjy-141/my-site.git
git push -u origin main
```

### 4. 配置 GitHub Actions 自动部署

新建 `.github/workflows/deploy.yml`：

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [ main ]

permissions:
  contents: write

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 11

      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'pnpm'

      - name: Install dependencies
        run: pnpm install

      - name: Build
        run: pnpm build

      - name: Deploy
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dist
```

> ⚠️ 注意：这里用的是 `pnpm/action-setup`，与本地 pnpm 保持一致，**避免 CI 中 npm/pnpm 混用**。

### 5. 开启 GitHub Pages

- 进入仓库 **Settings > Pages**
- **Source** 选 **Deploy from a branch**
- 分支选 **gh-pages**，文件夹选 **/(root)**
- 点击 **Save**

推送后等 Actions 跑完，访问 `https://zjy-141.github.io/my-site/` 即可。

| 修改内容 | 只改 `src/data/config.ts` |
| 换强调色 | 改 `config.ts` 的 `accentColor` |
| 加项目 | 在 `projects` 数组里加对象（使用 `links` 数组） |
| 本地预览 | `pnpm dev` |
| 重新部署 | `git add . && git commit -m "update" && git push` |
| 装新依赖 | **只用 `pnpm add`**，不要用 npm |
| 清理重装 | `Remove-Item -Recurse node_modules` + `pnpm install` |

## 十一、常见问题

| 问题 | 解决方法 |
|------|----------|
| TypeScript 报错“不存在属性 shijian” | 在 `config.ts` 的 `social` 中补上 `shijian` 字段 |
| 页面空白或样式错乱 | 检查 `vite.config.ts` 的 `base` 是否与仓库名一致 |
| GitHub Actions 失败 | 查看 Actions 日志，通常是 Node 版本或依赖问题 |
| 部署后图片不显示 | 确保图片路径是绝对路径或放在 `public` 目录 |
| 点击 Email 没反应 | 本地无邮件客户端；可改用“点击复制邮箱”或网页版邮箱链接 |
| 技术栈空白 | `skills` 必须是 `{ category, items }` 对象数组 |
| 项目链接不显示 | `projects` 的 `links` 字段必须是数组 |

---

## 十二、必须遵守的规则

1. **只用 pnpm**，永远不要在这个项目里运行 `npm install`。
2. **所有 import 用 `@/xxx`**，不要和相对路径混用。
3. **只改 `config.ts`** 就能更新网站所有内容。
4. **部署前改 `base`**，本地开发不需要。
5. **遇到报错先看终端**，Vite 的错误提示通常非常明确。
